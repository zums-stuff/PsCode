SCOPE
-----
Teacher/admin class management UI: /admin/classes list (join codes with
copy-to-clipboard, open links, delete), /admin/classes/new (admin-only create
form), /admin/classes/:id (inline rename, join code, members section,
assignments table with problem titles + submission counts, new-assignment
link), /admin/classes/:id/assignments/new (problem select + deadline),
/admin/assignments/:id (per-student best submissions table with expandable
read-only source view + rejudge via POST /api/runs). Ownership guard: a
teacher opening another teacher's class is redirected to /403; students are
redirected to /403 on the assignment detail.

Backend addition (the ONLY web/api change allowed by the brief):
GET /api/assignments/{id}/submissions in routes/assignments.py — per-student
best run (VERDICT_PRIORITY max, fewest steps tiebreak) among runs with a
summary_verdict, visible to the owning teacher or admin only (404 unknown
assignment, 403 non-owning teacher).

DEVIATIONS / NOTES
------------------
- API gaps (documented in issues.md, follow-up API todos needed):
  * No GET /api/classes/{id} (only /{code} string) -> class loaded from the
    GET /api/classes list and found by id.
  * No class-members endpoint -> MemberList is presentational, fed empty
    data (members self-register via the join code; no admin view exists).
  * AssignmentListItem has no class_id/problem_title/submission_count ->
    titles resolved from GET /api/problems, counts from per-assignment
    submissions calls; per-class filtering of the assignments list is
    impossible on the frontend (all assignments shown).
  * No DELETE /api/classes/{id} -> delete button wired, error surfaced
    inline (todo-22 precedent).
- Rejudge reuses POST /api/runs with {problem_id, source, mode:
  "assignment", assignment_id} — teacher/admin are exempt from
  ASSIGNMENT_CLOSED, so rejudge works after the deadline.
- SourceView is a read-only CodeMirror EditorView (editable.of(false) +
  pseint() + lineWrapping); jsdom needs the navigator.clipboard polyfill
  added to test/setup.ts (Storage/ResizeObserver/rAF/scrollIntoView already
  there).
- CodeMirror splits source text across token spans, so tests assert on the
  .source-view container's textContent, not a single-element text match.
- React Router v6 future-flag warnings on stderr are cosmetic (same as
  todo 22).
