## Runner design

`judge_submission(source, problem, test_cases, mode) -> SubmissionResult`

- **Parse ONCE (M1)**: `pseint_engine.parser.parse(source)` runs first. On
  `LexError`/`ParseError` → `SubmissionResult(verdict="CE", error={code:"CE",
  message, line, col})` with `cases == []`. ZERO test cases run, ZERO
  subprocesses spawned (proven by the spy test below).
- **Per-case subprocess**: `[sys.executable, "-m", "pseint_engine.cli", "run",
  source_path, "--input", input_path, "--seed", seed, "--report", report_path]`
  plus `--step-budget` (only when set), `--max-output-bytes` (default 1MB,
  matching the CLI default M13), `--max-array-elements` (only when set).
  - Source written ONCE to a `tempfile.NamedTemporaryFile` (`.psc` suffix),
    reused for all N cases, unlinked in `finally`.
  - Input written per case to a `.txt` temp file; report JSON to a `.json`
    temp file (mkstemp); both unlinked in `finally`.
  - `sys.executable` = the venv python → no PATH dependency.
  - Timing: `wall_ms` = `time.monotonic()` delta around `subprocess.run`;
    `cpu_ms` = `resource.getrusage(RUSAGE_CHILDREN)` user+sys delta (simplest
    reliable approach on Linux; single-threaded worker per submission).
  - Report read back as JSON; a missing/corrupt report (hard crash) degrades
    to a synthetic `ERR_INTERNAL` error record instead of raising.
- **Provisional verdicts** (error-based only; full taxonomy is todo 12):
  no error → `"OK"`; `ERR_STEP_LIMIT` → `"TLE"`; any other error → `"RE"`.
  Per-case record: `{verdict, steps, wall_ms, cpu_ms, output, error}`.
- **Lazy rules (M2)**: `"cf"` breaks after the first non-OK case; `"ioi"` and
  `"assignment"` run all cases; `"practice"` is a single run with
  `problem["input"]`, no grading (`cases == []`, output at top level).
- **Overall provisional verdict**: `"OK"` if all cases OK, else the first
  non-OK verdict (scoring/classification refined in todos 12/14).
- Unknown mode → `ValueError`.
