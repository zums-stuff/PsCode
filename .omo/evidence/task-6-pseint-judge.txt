SUBPROCESO/FUNCION COVERAGE
---------------------------
  Call with parens / without parens
  Por Valor (default for simple types): callee mutation NOT visible at caller
  Por Referencia: callee mutation visible at caller (same + different param name)
  Multiple params, mixed directions (swap)
  Funcion returns via Retornar expr; return_type conversion (Real)
  Recursion: factorial(10) == 3628800, steps = 71 (recorded)
  Recursion depth cap: infinite recursion -> ERR_RECURSION (SPEC §(i), 1000 frames)
  Callee steps count toward caller total (SPEC §(g))
  Retornar outside a function -> ERR_TYPE
  Undefined subproceso call -> ERR_TYPE

PARAM-DIRECTION SEMANTICS (official PseInt rules)
-------------------------------------------------
  Simple types default Por Valor; arrays default Por Referencia.
  Por Referencia binds the caller's variable via Env.bind_reference (alias),
  so reads/writes resolve outward to the caller's scope.

ARRAY COVERAGE
--------------
  Dimension + indexing (read/write), multi-dim m[2,3]
  Array index in expressions (a[0] + a[1])
  Bounds: a[3] on size-3 -> ERR_BOUNDS; negative index -> ERR_BOUNDS
  Undeclared array -> ERR_DIM
  Caps: 4 dims -> ERR_DIM; 1_000_000 elements -> ERR_DIM;
        5x1_000_000 total -> ERR_DIM (per-run 4_000_000 cap)
  Redimensionar resizes (preserves overlapping elements); on non-array -> ERR_DIM
  Array-by-reference mutation visible at caller (llenar(arr) -> arr[0]=42)
  Array literal [1,2,3]
  Uninitialized element read -> ERR_TYPE (strict, consistent with variables)

DESIGN DECISIONS
----------------
  - Arrays stored as mutable Array objects in Env (type "arreglo"); by-ref
    params alias the caller's name via Env refs, so mutation is visible.
  - Redimensionar mutates the Array object in place (by-ref arrays stay
    consistent across scopes).
  - sys.setrecursionlimit(20000): each PseInt frame costs ~6 Python frames,
    so Python's default 1000 limit would fire before the SPEC 1000-frame cap.
  - _ReturnSignal (noqa N818) is control flow, not an error: it unwinds
    nested blocks when Retornar fires inside a Funcion.
  - SUBCADENA is 1-indexed inclusive (official PseInt semantics).
  - REDON rounds half away from zero (floor(x+0.5) / ceil(x-0.5)).
