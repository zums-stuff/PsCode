NOTES
-----
  - ParseError carries code="CE", message, line (1-based), col (0-based).
  - Unterminated structures report the opening keyword's position.
  - Built-in function names (abs, azar, subcadena, ...) are keyword tokens
    from the lexer but are parsed as FunctionCall in expression position.
  - Para accepts both '=' (SPEC EBNF) and '<-' (real PseInt); Definir init
    accepts both too.
  - 'Como' is an IDENTIFIER from the lexer; the parser treats it as the
    type separator in Definir contextually.
  - 'Mientras Que' is lexed as MIENTRAS + IDENTIFIER("Que"); the parser
    recognizes the pair as the do-while tail, allowing nested Mientras loops
    inside the HACER block.
