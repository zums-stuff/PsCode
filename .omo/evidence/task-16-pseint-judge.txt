## Design decisions
- **Composite PKs replace redundant UniqueConstraints**: class_members/contest_participants/contest_problems/contest_team_members use composite PKs only. The initial autogenerate emitted both PK + named UniqueConstraint; `alembic check` flagged drift because PG's composite PK already implies uniqueness and alembic omitted the redundant constraint. Removed the redundant UniqueConstraints from models → zero drift.
- **Bootstrap admin (M12)**: `bootstrap_admin(Session(op.get_bind()))` at the end of the initial migration's `upgrade()`. Reads `ADMIN_USERNAME`/`ADMIN_PASSWORD` env; no-op if unset or user exists (idempotent); password hashed with pwdlib argon2 (same lib todo 17 uses).
- **alembic/env.py**: URL always from `config.database_url()` (env `DATABASE_URL` with local default) — credentials never committed in alembic.ini. Tests set `DATABASE_URL` env var to point at the test DB.
- **Tests use postgres, not SQLite**: dedicated `pseint_test` DB on the same docker postgres, created/dropped per test session, migrated to head via alembic programmatically.
